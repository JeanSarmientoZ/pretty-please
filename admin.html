Conexión a Base de Datos en Supabase (Opcional)

Para sincronizar tu catálogo entre múltiples computadoras y celulares en la nube.

¿Para qué sirve esta pestaña? (Información Clara)

¡No necesitas configurar nada aquí si solo tú administras la tienda!
Actualmente todas las prendas, precios y cambios que haces en este panel se guardan de forma instantánea en tu navegador (localStorage) y tus clientes ya los pueden ver en la tienda web.

¿Cuándo se usa Supabase? Supabase es una base de datos externa gratuita en la nube. Te servirá únicamente si en el futuro tienes un equipo de 2 o más personas administrando la tienda a la vez desde distintas computadoras y necesitan que todo se sincronice al segundo en la nube.

Script SQL para Supabase (Solo si decides conectarlo en el futuro):

CREATE TABLE prendas (
  id BIGSERIAL PRIMARY KEY,
  nombre TEXT NOT NULL,
  categoria TEXT NOT NULL,
  precio NUMERIC(10,2) NOT NULL,
  precio_regular NUMERIC(10,2),
  badge TEXT,
  imagen TEXT NOT NULL,
  tallas TEXT[] DEFAULT '{S,M,L}',
  colores TEXT[] DEFAULT '{#C51F3D,#E6B8B9}',
  disponible BOOLEAN DEFAULT TRUE,
  created_at TIMESTAMP WITH TIME ZONE DEFAULT NOW()
);
